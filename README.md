# Палочки

Браузерная игра: на столе 21 спичка, за ход можно взять 1, 2 или 3. Кто взял последнюю — проиграл.

Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
py -3 -m http.server 8765
```

Затем перейдите на http://127.0.0.1:8765/

Режимы: против компьютера (лёгкий / сложный) и вдвоём за одним столом.
